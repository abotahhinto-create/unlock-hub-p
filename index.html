📖 دليل الاستخدام الشامل

1️⃣ التوصيل

وصّل الهاتف بكابل USB أصلي. فعّل "تصحيح أخطاء USB" من خيارات المطور (Settings → About → اضغط Build number 7 مرات → Developer options → USB Debugging).

2️⃣ اختيار الجهاز

صفحة "الأجهزة" ← اختر الماركة والموديل. ستظهر أزرار العمليات.

3️⃣ فك FRP

صفحة "فك القفل" ← اختر الطريقة ← تنفيذ. لأندرويد 16 استخدم Sigma/UMT.

4️⃣ التعريب

صفحة "التعريب" ← اختر إصدار أندرويد والدولة ← تطبيق.

5️⃣ الشبكة و 3G

صفحة "الشبكة" ← اختر الوضع أو حوّل Sprint → GSM.

6️⃣ الفرمتة

صفحة "الفرمتة" ← اختر الطريقة (ADB/Fastboot/Recovery).

7️⃣ حسابي والاشتراك

صفحة "حسابي" ← أنشئ حساباً أو سجّل دخول. أول 10 عمليات مجانية. بعدها فعّل الاشتراك (30$/سنة) عبر التواصل مع المصمم.

8️⃣ التثبيت على الهاتف (PWA)

افتح التطبيق في Chrome على الهاتف ← قائمة (⋮) ← "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق".

⚠️ تنبيهات

• هذه النسخة تعمل في المتصفح وتحاكي الأوامر. للتنفيذ الفعلي على الهاتف، اربط التطبيق بأداة Tauri/Electron (راجع الدليل الفني).

• أندرويد 16 على سامسونج يتطلب أدوات خارجية.

• الاستخدام القانوني فقط على الأجهزة التي تملكها.
